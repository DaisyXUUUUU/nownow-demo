# NowNow 闹闹

一款以地图为核心的城市活动与本地创作发现 App。当前 V0.1 Demo 场景设定在金华。

## 已完成的交互

- 发现页：时间、类型筛选，精选活动和创作者入口
- 原型地图：活动/创作者图层、标记点击、缩放、搜索、筛选
- 活动详情：时间地点、票务、主办方、来源、关联创作者、收藏
- 创作者主页：个人介绍、作品、开放工作室、近期出现地点、关注
- 收藏页：活动和创作者的本地状态演示
- 限时礼物：活动礼物标记、礼物活动筛选、发售与获取信息、开售提醒
- 闹闹 AI 助手：全局悬浮入口、快捷提问、本地活动/礼物检索与可点击推荐卡片
- 入驻页：活动主办方和创作者两套提交表单
- 手机尺寸 Web 外壳，同时兼容 Expo iOS/Android

> 所有活动、创作者、作品及组织名称均为产品功能测试而虚构。

## 启动

```bash
npm install
npm run web
```

也可以运行 `npm run ios` 或 `npm run android`。

## 当前地图说明

V0.1 使用无需密钥的交互式原型地图，目的是先验证信息结构和操作体验。它不是实际地理瓦片，不能导航或读取设备定位。真实地图接入计划见 [API_INTEGRATION.md](./API_INTEGRATION.md)。

## 目录

- `App.tsx`：手机端交互与主要组件
- `src/data.ts`：金华功能测试数据
- `src/types.ts`：领域类型
- `src/theme.ts`：NowNow 品牌色与圆角系统
- `assets/icon.png`：已确认的“闹闹”吉祥物 App 图标
- `assets/events/`：活动和创作者 Demo 图片
